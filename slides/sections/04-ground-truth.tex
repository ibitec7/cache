\section{Ground truth}

\begin{frame}{Ground truth is exact, not simulated}
  \begin{itemize}
    \item The curve is $\mathrm{MRC}(C) = \Pr(R \ge C)$ over the held-out
      block's own backward reuse distances.
    \item Exact for LRU: a request hits iff its reuse distance is below the
      capacity (stack property).
    \item Verified against a full LRU replay on the same trace: identical.
    \item No sampling and no simulator, so no sampling correction and no band.
  \end{itemize}
  \vspace{1em}
  \begin{block}{Identification limit}
    A distance beyond $b_{M-1}$ is not observable in a finite window, so every
    reported capacity sits below it.
  \end{block}
\end{frame}

\begin{frame}{Metrics}
  \begin{description}
    \item[Curve error] MAE and MAX absolute deviation from the exact curve
      over the frozen capacity grid.
    \item[Shape error] signed bias, mean relative error, and the area between
      curves, integrated in log capacity.
    \item[Decision error] capacity needed to reach a target hit ratio, as a
      ratio to the true capacity.
  \end{description}
  \vspace{0.6em}
  \begin{block}{Rule}
    An error is never read below the truth's own sampling error,
    $\sqrt{p(1-p)/n}$ on the block. On cluster45 the hazard sits inside it.
  \end{block}
\end{frame}
