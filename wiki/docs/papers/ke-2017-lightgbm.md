## What it did

Presented two techniques that make gradient boosting fast on large, high-dimensional
data: Gradient-based One-Side Sampling, which keeps all high-gradient instances and
a random subset of the rest when estimating split gains, and Exclusive Feature
Bundling, which packs mutually exclusive sparse features into single features. With
leaf-wise tree growth these give large speedups over level-wise GBDT at comparable
accuracy, and the implementation became the default tabular learner.

## The one idea this project borrows

The learner itself, used as a hazard classifier over (episode, bucket) rows. The
specific properties that matter here: native categorical handling for namespace,
operation and client id without one-hot expansion; `binary` objective giving
calibrated probabilities per bucket; and fast enough training that Optuna can run
hundreds of trials on 14 TB-class data without sampling the labels.

## What this project does differently

Nothing about the algorithm. The difference is the problem it is applied to: the
targets here are thousands of per-bucket binary labels generated by censoring-aware
row construction, not a single classification. The modelling risk therefore sits in
row construction and calibration, not in the booster.
