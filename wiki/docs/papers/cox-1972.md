## What it did

Introduced the proportional hazards model: the hazard of an event is a baseline
hazard times a multiplicative factor $\exp(\beta^\top x)$ that depends on
covariates. The baseline is left unspecified, and $\beta$ is estimated by partial
likelihood using only the ordering of events, which makes the model robust to the
shape of the baseline and is why it became the default regression tool for
time-to-event data.

## The one idea this project borrows

The structural claim that covariates act on the hazard, and that a survival curve
can therefore be built for a profile rather than for a dataset. That is the whole
premise of predicting an MRC for an untraced cluster: estimate how metadata shifts
the hazard, integrate it into a curve.

## What this project does differently

Cox assumes the multiplicative form with a linear index $\beta^\top x$ and an
unspecified continuous baseline. This project uses no functional form at all: a
GBDT learns an arbitrary hazard surface over the features, in discrete time, with
the interaction structure learned rather than assumed. The trade is
interpretability, partial-likelihood efficiency and asymptotic theory for
flexibility, which has to be paid for with a held-out-cluster evaluation
([Experiments](../experiments.md)).

`src/mrc/hazard.py` (optional Cox baseline reported as a reference model),
